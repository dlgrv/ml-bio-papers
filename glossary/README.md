# Глоссарий

Единые переводы терминов для всех статей репозитория: один термин — один перевод, везде одинаковый.

**Первое употребление в статье:** русская форма + английский оригинал в скобках, например `рид (read)`. Если в «Примечании» дано определение для читателя (не инструкция переводчику), его тоже включают при первом упоминании: `рид (read; короткий фрагмент ДНК после секвенирования)`. Дальше — только русский термин.

**Аббревиатуры** (LCA, CHT, PPV…): при первом употреблении полный русский перевод + `(ABBR)`, дальше только аббревиатура. Полный английский в скобках для них не дублируют.

**Примечание:** определения для читателя попадают в текст при первом упоминании; инструкции переводчику (`не «эталонная»`, `не переводить`, `при первом употреблении — …`) в статью не переносят.
